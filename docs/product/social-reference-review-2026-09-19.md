# 2026-09-19 社群參考：產品取捨

六個連結含一個重複，共五篇。已在同一個 Chrome 分頁閱讀主文與當時可見留言；不是全部留言、沒有實測這些專案，也不以作者績效宣傳當成證據。本次只記錄參考，不增加目前已核准的功能範圍。

## 1. OpenStock：借鏡資訊整合，不照搬資料與部署方式

[主文](https://x.com/fhwofjow51260/status/2100569731522781650)推廣 OpenStock 的行情、新聞、自選與 AI 郵件摘要。[專案 README](https://github.com/Open-Dev-Society/OpenStock)可核對 Finnhub、TradingView、MongoDB、Inngest、Gemini 與郵件服務等依賴；不能把開源等同所有資料免費、即時。授權為 AGPL-3.0，未引入程式碼。

可見留言提出情緒資料延遲、多個服務需帳號／金鑰，以及每日郵件是否真的有人使用；均是值得驗證的問題，不是已證明缺陷。

**保留**：從自選、變化摘要到個股來源的連續操作。**不直接採納**：雲端持股、郵件流程、多來源堆疊；要先證明本人每天願意用，且逐項確認資料覆蓋、時間與成本。

## 2. Serenity stock choke：保留問題框架，不增加另一個 Agent

[主文](https://x.com/smartpigai/status/2099720762144035171)與 [GitHub](https://github.com/fadewalk/serenity-stock-choke)、[SKILL 原文](https://github.com/fadewalk/serenity-stock-choke/blob/main/SKILL.md)已閱讀。框架沿產業鏈找供應瓶頸，再作正反論證；包含 A 股特定流動性、機構關注等篩選規則。作者列舉漲幅不是可重現回測。可見留言也有人質疑實效，未看到獨立驗證。

**保留**：供應替代難度、擴產時間、公司實際受益業務、反證與失效條件。**不採納**：把瓶頸敘事直接變成評分或買進結論，也不照搬市場特定門檻。StockTool 已有 `serenity_agent.py`；先改善證據與解釋，不因文章再增加 Agent。

## 3. Roan：交易績效宣傳尚無足夠證據

[主文](https://x.com/rohonchain/status/2099534337645719753)宣稱以多模型、多代理建立全天候交易系統，列出 Sharpe、回撤與勝率目標。可見留言主要是作者附件與交易紀律討論，未看到獨立重現。這不是 OpenAI 官方驗證。

[作者留言附件](https://drive.google.com/file/d/14kB6_agfA-DFko36EIaS2d1YBoWFnrJL/view)為六頁 `GPT-6 astra HEDGE FUND.pdf`：已確認公開閱覽與第一頁，但**完整附件尚未讀完**；不採用 Drive 自動 AI 摘要代替原文。未取得可核對的交易紀錄、成本設定、樣本外結果與完整可重現程式。

**保留待研究**：實驗紀錄、失效停用與可回復設計。**不採納**：自動交易、績效承諾、以代理数量推論研究品質。這些偏離目前個人研究助手目標。

## 4. Jesse：研究驗證流程值得參考，交易功能暫不擴張

[主文](https://x.com/_zheergen/status/2099006265573953845)（重複網址只計一次）與 [Jesse README](https://github.com/jesse-ai/jesse)支持其策略回測、模擬／實盤、最佳化及 MCP 等功能描述；未安裝或驗證效能。

可見留言提醒滑價、不同期間失效、樣本外與 Monte Carlo；作者也承認 MCP 本身不證明策略有效。詢問實盤績效的留言未見可驗證結果。

**保留**：同一策略定義、可追溯進出場原因、成本與樣本外比較。**延後**：加密交易、實盤下單與參數搜尋擴張。先確認現有回測能否回答使用者問題。

## 5. 影片變成產業研究：最貼近使用者的未來輸入方式

[原分享](https://www.threads.com/share/BAOVYrgpon/)已確認對應[原文](https://www.threads.com/@foptwasg/post/DdOqMKjjWyf)。作者展示 YouTube 內容轉成產業鏈與公司研究，宣稱目前偏半導體／AI。可見留言詢問 GitHub 與關聯是否代表因果；作者的回覆未提供可核對專案連結，也未證明因果辨識能力。**專案身分未復原，未完整驗證影片示範。** 留言中的公司／材料敘述不當作已核實公司事實。

**保留為後續產品假設**：文章／影片 → 原作者主張與時間戳 → 公司／產品辨識 → 官方資料核對 → 保存待研究問題。必須區分「作者說法、系統推論、已核對事實」，不能把產業關聯圖當因果或投資機會證明。

## 優先順序

先完成目前的可信公司研究與外部 AI 邊界；下一批規劃才比較「文章／影片導入研究」和「自選股每日變化」哪個更能降低本人的研究門檻。這些文章不構成實作核准，也不改變本批 Sol 獨立驗收要求。
