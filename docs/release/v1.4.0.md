# StockTool v1.4.0

發布日期：2026-08-29

## 主要內容

- Prediction Lab：保存預測後，以 5／20 個市場交易日追蹤結果。
- 市場邊界：TWSE、TPEx 與美股採市場限定 benchmark 及官方交易日曆。
- 公司行動：拆股、股利或調整資料不完整時，結果會停止在不可評估狀態，
  不會產生看似可信的超額報酬。
- 研究延續：保存的研究版本可重開，不會在重開時重新抓取供應商或 AI 資料。
- 發布完整性：候選 EXE、Payload 與安裝程式均以 SHA-256 綁定並經隔離生命週期驗證。

## 使用與限制

- 本工具僅供研究、學習與風險分析，不會自動下單，也不構成個人化投資建議。
- 外部免費資料可能延遲、缺漏或改變格式；資料不足時功能會明確標示 unavailable。
- Windows 安裝程式目前未做程式碼簽章，因此系統可能顯示未知發行者警告。
- 使用者資料位於 `%LOCALAPPDATA%\StockTool`，升級不應覆寫持股、自選股、研究庫或設定。
