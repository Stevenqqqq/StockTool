# StockTool v1.4.3 MU r2 個人交付

2026-09-30 使用者核准更新本機、同步來源及私人 GitHub Release；原 v1.4.3 Release 保留，不覆寫舊資產。新識別為 `v1.4.3-mu-r2`，程式內版本仍為 1.4.3，不因改版號重新編譯已驗收的 EXE。

## 已驗收修正

- 公司來源失敗時，頁首與公司資料狀態明示缺口，可重新讀取；價格與評分仍保留。
- 指標權重覆蓋率不是公司研究完整度。取得基本或有限官方資料後，不再誤稱所有研究資料已就緒。
- 最後 EXE 已獨立操作查詢失敗、失敗重試、公開來源恢復後重試；恢復仍明示營運／收入證據不足。
- 1280／760px 的覆蓋率標籤、價格與完整日期均通過可見畫面及 DOM 核對。
- 5,692 檔案全數符合送驗清單；目前 163 個 src Python 檔符合建置來源；獨立定向 28 項測試通過。實作者完整回歸為 1,781 passed／2 warnings，在最後兩行變數更名前執行；不宣稱對更名後重新跑完整回歸。

## 資料與回復邊界

安裝仍為每位使用者 `%LOCALAPPDATA%\Programs\StockTool`，桌面與開始功能表使用固定入口。使用者資料在 `%LOCALAPPDATA%\StockTool`；不遷移、不覆寫、不刪除。升級前程式、資料及捷徑均另行備份並逐檔核對；升級後再次核對既有資料。私人備份與資料清單不放入 GitHub。

## 保留限制

- 安裝器未簽章。guest 升級／解除安裝生命週期未執行，沿用既有使用者核准主機交付豁免；主機結果不是 guest 證據。
- 最後 EXE 恢復取得有限官方文件；純「只有基本資料、零官方文件」變體只有程式／定向測試，不冒充最後 EXE 實測。
- 外部 AI、個人保存研究庫內容與解除安裝沒有在本批新增驗證。來源成功是當次觀察，不保證之後供應商可用。
- 僅延後缺口長段落、重複 HTTP 403 等可讀性整理，不刪除實際缺口。
