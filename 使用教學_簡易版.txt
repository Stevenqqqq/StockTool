股票分析工具 使用教學_簡易版

一、這個工具是什麼

這是研究、學習與風險分析用的股票分析工具。
它不是投資顧問，不保證獲利，不會自動下單，也不預測明天一定漲跌。
所有回測結果都只是歷史資料下的模擬結果，不代表未來報酬。

二、最簡單啟動方式

1. 開啟 release\StockTool\
2. 點兩下 StockTool.exe
3. 系統會嘗試自動開啟瀏覽器
4. 如果瀏覽器沒有自動開啟，請手動打開：
   http://localhost:8501
5. 如果 8501 被占用，工具會嘗試使用：
   http://localhost:8502

也可以點兩下：

啟動股票工具.bat

三、資料匯入方式

EXE 版本的資料會儲存在：
%LOCALAPPDATA%\StockTool\data\processed\stock_data.sqlite

之後打開 StockTool.exe 時，系統會自動讀取這個 SQLite 檔案。
如果畫面已有資料，就不需要再手動上傳 CSV。

不是只能看 2330。
要加入其他股票，請進入「自動抓資料」頁面，自己輸入代號：
台股上市：6789 會自動查 6789.TW
台股上櫃：6488 會自動查 6488.TWO
美股：AAPL 會直接查 AAPL

下載成功後會自動存進 %LOCALAPPDATA%\StockTool\data\processed\stock_data.sqlite。
下次重新打開 StockTool.exe，已抓過的股票會一起載入。

如果某些頁面顯示「資料不足」：
通常是缺少基本面或估值資料，不是股票不能分析。
股價資料可以自動抓；財報、EPS、PE、PB、殖利率等基本面資料目前仍需要 CSV 或範例資料。
AI 分析頁會先給「可用資料評分」，完整 0-100 總分則需要技術面、基本面、估值面、風險面都齊全。
「分數原因」頁籤會把每個分項拆成「優點」和「缺點 / 需要檢查」，比較容易看懂為什麼分數高或低。

研究首頁每天會先整理本機持股、自選股與既有研究資料：今日關注、持倉快照、自選股動態、繼續研究與待處理事項。每個提醒都會顯示資料依據與資料日期；資料不足時不會硬算。

成功搜尋後會進入 Research Workspace，把公司介紹、圖表、評分、基本面、風險與資料來源放在同一份研究快照。
畫面的「情境參考區間」使用 20 日均線、60 日均線、近 20 日高低點與 ATR，僅作為研究用觀察區間，不是買進建議，也不保證能成交或獲利。
它會顯示計算基準日、假設、區間、突破觀察值與風險參考值；突破觀察值可能高於現價很多，代表條件觸發值，不代表現價附近的交易建議。

全自動查詢：
首頁和「AI 分析與評分」頁都有「全自動查詢 / 補資料」。
輸入股票代號後，系統會自動：
1. 查本機 SQLite
2. 沒有股價就自動下載

「更新今日資料」：
1. 需要由使用者在研究首頁主動按下。
2. 只更新持股與自選股中市場已明確的股票，最多 20 檔。
3. 每檔會顯示資料來源、實際查詢代號與最後資料日期；個別失敗不會中斷其他股票。
4. 此功能不會新增、移除或覆寫你的持股與自選股清單。
3. 能抓到基本面就自動補
4. 存到 data\processed\stock_data.sqlite 和 data\processed\fundamentals_auto.csv
5. 重新計算技術指標與評分

注意：免費資料源不是每檔股票都有完整基本面。
缺資料時系統會明確顯示，不會亂補假資料。

方法 A：CSV 上傳

1. 進入「資料匯入」
2. 上傳包含以下欄位的 CSV：
   date, symbol, open, high, low, close, volume, adjusted_close
3. adjusted_close 可以空白
4. 系統會檢查缺欄位、日期、重複資料、價格異常與負成交量
5. 缺值會顯示警告，不會自動補假資料

方法 B：自動抓資料

1. 進入「自動抓資料」
2. 輸入股票代號，例如 2330、6488 或 AAPL
3. 選擇市場：
   台股上市 TWSE：可輸入 2330 或 2330.TW，實際查詢 2330.TW
   台股上櫃 TPEx：可輸入 6488 或 6488.TWO，實際查詢 6488.TWO
   美股 US：可輸入 AAPL，實際查詢 AAPL
4. 可選擇起始日與結束日
   如果留空，起始日預設為今天往前 2 年，結束日預設為今天
5. 選擇資料來源：
   自動備援：依序嘗試 yfinance、FinMind、快取
   yfinance：優先用 yfinance
   FinMind：需要 FINMIND_TOKEN
   快取：只讀 data\cache
   CSV 上傳：請改到「資料匯入」頁面
6. 按「抓取股價資料」
7. 抓到的資料會自動放入目前分析流程

注意：
自動抓資料使用免費公開資料來源，資料可能不完整。
如果網路失敗且沒有快取，系統會報錯，不會產生假資料。

方法 C：產業 / 概念股查詢

如果你不是要輸入單一股票，而是想找某個產業或概念：

1. 進入「產業 / 概念股查詢」
2. 輸入關鍵字，例如：
   半導體、AI、AI伺服器、HBM、封裝、矽電容、CoWoS、CoPoS、TGV、CPO、矽光子、電動車、綠能、資安、雲端、金融、航運
3. 選擇市場：
   台股上市 TWSE
   台股上櫃 TPEx
   美股 US
4. 按「線上查詢並更新」
5. 系統會優先使用線上資料：
   台股：TWSE / TPEx 官方公開資料
   美股：yfinance 搜尋與產業篩選
6. 查到候選股票後，可自動更新前 N 檔股價與基本面
7. 更新成功的資料會存到：
   data\processed\stock_data.sqlite
   data\processed\fundamentals_auto.csv

注意：
交易所產業分類不等於完整概念股清單。
輸入 HBM 時，系統會同時列出直接記憶體製造商與相關供應鏈，但會在「關聯類型」標示清楚。台股若是先進封裝、測試、載板、設備或材料鏈，會標成供應鏈關聯，不會標成 HBM 製造商。
輸入封裝或先進封裝時，系統會優先列出先進封裝、封測、載板、設備與測試相關候選股，並在備註欄顯示個股角色，例如日月光投控屬主要封測與先進封裝服務商之一。NVDA、AMD 若出現，會標示為晶片設計 / 先進封裝需求端，不是封裝代工廠。
部分題材會顯示「股價反應階段」。例如矽電容會標為「初期觀察」，代表題材仍需觀察量產、客戶認證、營收占比與股價是否已提前反映；這不是買賣建議。
yfinance 免費資料可能缺漏或分類不一致。
查詢結果只是研究索引，不是買賣建議。

四、data/cache 快取

自動抓到的股價資料會儲存在：

%LOCALAPPDATA%\StockTool\data\cache\

下次抓相同股票與日期區間時，可直接使用快取。
如果想重新下載，請在「自動抓資料」勾選「忽略既有快取並重新下載」。

五、自選股清單

1. 進入「自選股清單」
2. 輸入股票代號、市場與備註
3. 按「加入 / 更新自選股」
4. 自選股會儲存在：
   %LOCALAPPDATA%\StockTool\data\watchlist.csv

六、AI 分析與綜合評分

1. 先用「自動抓資料」或「資料匯入」載入股價資料
2. 進入「AI 分析與評分」
3. 選擇股票代號
4. 系統會自動計算技術指標，並顯示：
   研究分數
   全資料總分
   技術面、基本面、估值面、風險面分數
   AI 摘要
   策略健檢
   風險與資料限制

綜合評分權重：

技術面 30%
基本面 30%
估值面 20%
風險面 20%

如果尚未匯入基本面資料，全資料總分會顯示資料不足。
這時仍可看「研究分數」，但不要把它當成完整評分。
若 PE / PB 已有資料但缺少股利殖利率，系統會保守計算估值分數，並把缺漏欄位列在資料限制中。

AI 摘要是本機規則式摘要，不會連外部 AI，不會預測明天漲跌，也不是買賣建議。

「公司業務脈絡」頁籤會補充：
1. 公司主要在做什麼
2. 技術特點
3. 連結到哪些產業或題材
4. 目前可能應用在哪
5. 未來可能應用在哪
6. 瓶頸與需要查證的問題

這些內容會使用 yfinance 公司基本資料與本機規則式題材對照。
若系統能辨識更細的供應鏈角色，會優先補上產品重點，例如 HBM / AI 記憶體、NAND / SSD 儲存、機器人減速器、伺服控制、工業電腦或整機平台。
如果公司描述不足，系統會明確顯示資料不足，不會亂編。
題材關聯只是研究索引，不代表公司營收占比，也不是買賣建議。

「Serenity 小 Agent」頁籤會把供應鏈瓶頸研究框架整理成檢查表。
它會看：
1. 公司業務與技術特點
2. 技術指標與股價反應
3. 綜合評分與缺漏資料
4. 你匯入的研究報告摘要

它會輸出：
1. 研究匹配度
2. 供應鏈瓶頸強度
3. 架構遷移關聯，例如 HBM、CPO、先進封裝、800V、人形機器人
4. 證據品質
5. 可能催化
6. 失效條件
7. 風險與下一步查證問題

注意：
這個小 Agent 是研究假設檢查，不是買賣建議。
如果缺少年報、法說、客戶認證、量產、訂單、股本稀釋或市場占有率資料，畫面會列在「證據缺口」。
社群文章或第三方摘要只能當線索，不能當成已驗證事實。

七、研究報告摘要

1. 進入「研究報告摘要」
2. 上傳 PDF，或在本機版輸入 PDF 路徑，例如：
   D:\Downloads\矽力-KY 分析.pdf
3. 輸入股票代號，讓摘要可以和「AI 分析與評分」頁關聯
4. 按「產生研究報告摘要」
5. 系統會整理：
   研究重點
   主要業務
   技術特點
   產業連結 / 應用場景
   可能催化
   瓶頸 / 需要驗證
   估值觀察
   風險

匯入後，「AI 分析與評分」頁的「研究報告」分頁會顯示同股票代號的報告摘要。
這是本機規則式摘要，不會自動爬付費券商報告，也不是買賣建議。
如果 PDF 是掃描圖片，目前可能無法抽字，會顯示資料不足。

八、股票篩選器

1. 先匯入或自動抓取股價資料
2. 進入「技術指標」計算指標，或在「股票篩選器」按下計算按鈕
3. 設定成交量、20 日報酬率、20 日波動率、RSI 區間
4. 系統會列出符合條件的股票

如果缺少某個指標欄位，系統會顯示警告，不會假裝已完成篩選。

九、投資組合管理

1. 進入「投資組合管理」
2. 手動輸入股票代號、零股股數（股）、平均成本（每股）與市場
3. 按「加入 / 更新持股」
4. 系統會先用目前載入的股價與 %LOCALAPPDATA%\StockTool\data\processed\stock_data.sqlite 裡已保存的股價估算市值、權重與未實現損益
5. 投資組合資料會儲存在：
   %LOCALAPPDATA%\StockTool\data\portfolio.csv

持股數量以「股」為單位，支援零股。
例如輸入 37 代表 37 股，不是 37 張；若要記錄 1 張台股，請輸入 1000 股。

如果某些持股顯示沒有最新價格，代表本機資料庫還沒有那檔股票的股價。可以在投資組合頁按「自動補齊缺少股價」嘗試線上抓取；台股 TW 會自動嘗試上市/上櫃代號，美股會用原始美股代號。若代號不存在或免費資料源沒有資料，系統會顯示原因，不會用假價格補值。

這只是手動紀錄與風險分析，不會連接券商，也不會下單。

Excel 報表與其他輸出預設放在：

%LOCALAPPDATA%\StockTool\reports\

EXE 版本中的輸出位置是：

%LOCALAPPDATA%\StockTool\reports\

十一、錯誤紀錄

如果 EXE 開不起來或瀏覽器沒有出現，請查看：

%LOCALAPPDATA%\StockTool\logs\

裡面的最新檔案：

streamlit_*.log
streamlit_*_error.log

十二、常見問題

1. Windows 防火牆跳出提示
   Streamlit 是本機服務。通常允許私人網路即可，不需要開放公用網路。

2. 防毒軟體警告
   PyInstaller 打包的 EXE 可能被誤判。請確認檔案是自己本機打包產生。

3. 連接埠 8501 被占用
   工具會嘗試 8502。若兩個都被占用，請先關閉其他 Streamlit 或本機服務。

4. 報表資料夾無法寫入
   請確認 %LOCALAPPDATA%\StockTool\reports\ 存在，且目前 Windows 使用者有寫入權限。

5. 自動抓不到資料
   可能是免費公開來源沒有該股票、日期區間無資料、網路問題或代號格式不同。
   請改用 CSV 上傳作為備援。

十三、重要風險提醒

本工具不提供保證獲利、不提供個人化投資建議、不自動下單。
回測可能受到前視偏誤、存活者偏誤、交易成本、流動性與資料品質限制影響。
使用任何結果前，請檢查資料來源、日期範圍、交易成本、滑價與風險揭露。

十四、v1.1.0 發布版與安全關閉

1. 一般使用者請點 release\StockTool\StockTool.exe。
2. build_exe.bat 只會產生 release\staging\StockTool，不會直接覆蓋正式版。
3. 維護者確認 staging 版本可用後才執行 publish_release.bat；舊 release 會保留在 release\previous\StockTool。
4. 關閉工具時，請回到啟動視窗按 Ctrl+C，等待「正在停止股票分析工具」後再關閉視窗。
5. 8501 被占用會自動改用 8502；兩個都被占用時，請先關閉其他本機服務，再查看 logs\launcher_*_error.log。
6. 如果瀏覽器沒有開啟，請手動輸入啟動視窗顯示的 localhost 網址。
7. online 表示剛從 provider 下載，cache 表示本機快取，sample 是範例資料，stale/partial 表示資料不完整或可能過期。它們都不是買賣建議。

十五、v1.2.0 Benchmark 與可重現性報表

1. Excel 與 HTML 報表會列出 Benchmark、資料來源、資料品質與可重現性 Manifest。
2. Benchmark 必須與策略資金曲線的交易日期及研究期間完整對齊；系統不會自動補齊遺漏日期。
3. 若 benchmark 缺少必要資料、日期重複或無法對齊，報表會顯示「資料不足」，不會把缺值當成 0%。
4. Manifest 可用來核對輸入雜湊、資料來源、策略參數、交易成本、風控參數與關鍵輸出。
5. Manifest 不會保存私人投資組合、API 憑證、原始 PDF 或完整原始行情；它也不能單獨重新下載外部歷史資料。
6. benchmark 與回測的歷史結果僅供研究與風險分析，不代表未來報酬，也不構成買賣建議。
