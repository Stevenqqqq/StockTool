# StockTool Governance

- The user owns final product decisions and approvals.
- ChatGPT serves as CTO, architecture planner, and independent acceptance reviewer.
- Codex Luna implements only approved scope.
- Only one Sprint may be active at a time; do not start the next Sprint before acceptance.
- Reviews do not modify code. Implementation and acceptance remain separate activities.
- Every Sprint requires targeted tests, full pytest, coverage, quality checks, EXE smoke testing, and a release privacy scan.
- Never modify, move, or overwrite real user data.
- Sprint 33.1.1 / StockTool v1.4.0 is the current formal acceptance baseline.
- The detailed roadmap and scope sequence are defined in `PRODUCT_EXECUTION_PLAN.md`.
